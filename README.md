# Tetris (SDL3)

C++17 と [SDL3](https://github.com/libsdl-org/SDL) で作った、シンプルなテトリスです。
描画・サウンド・入力はすべて SDL3 だけで処理しており、ほかのライブラリは使っていません。

## ゲーム内容

- 10列 × 20段の盤面に、7種類のミノ（I・O・T・S・Z・J・L）が落ちてきます。
- 横一列をそろえるとラインが消え、得点になります。
- ブロックが出現位置まで積み上がるとゲームオーバーです。

### 主な仕様

| 項目 | 内容 |
|---|---|
| ミノの出る順番 | 7種類を1巡ずつシャッフルして出す（7-bag 方式） |
| NEXT 表示 | 次のミノを1つ表示 |
| ゴースト | 今のミノをそのまま落としたときの着地位置を半透明で表示 |
| 回転 | 時計回り・反時計回りの両方に対応。壁際では左右に最大2マスずらして回す（簡易壁蹴り） |
| レベル | 10ライン消すごとに1上がる |
| 落下速度 | レベル0で 0.8 秒に1段。レベルが1上がるごとに 0.07 秒速くなり、最速は 0.1 秒 |

### 得点

| 操作 | 得点 |
|---|---|
| 1ライン消し | 100 ×（レベル + 1） |
| 2ライン消し | 300 ×（レベル + 1） |
| 3ライン消し | 500 ×（レベル + 1） |
| 4ライン消し | 800 ×（レベル + 1） |
| ソフトドロップ | 1マスごとに 1 |
| ハードドロップ | 1マスごとに 2 |

### サウンド

- BGM はループ再生されます。
- ブロックが14段以上に積まれると、ピンチの演出として BGM が 1.25 倍速になります（音程も上がります）。
- 効果音は、左右移動・回転・着地・ライン消去・4ライン消し・ゲームオーバーのときに鳴ります。

### ゲームオーバー

1. 盤面のブロックが上の段から順にグレーに変わります。
2. 画面が暗くなり、`GAME OVER` がフェードインします。
3. `RESTART`（最初からやり直す）と `QUIT`（ゲームを終了する）を選べます。

ゲームオーバーになると BGM は止まり、再スタートすると頭から流れます。

## 操作方法

### プレイ中

| キー | 操作 |
|---|---|
| ← → | 左右に移動 |
| ↓ | ソフトドロップ（1段ずつ速く落とす） |
| Space | ハードドロップ（一気に落として固定する） |
| ↑ / X | 右回転（時計回り） |
| Z | 左回転（反時計回り） |
| R | 最初からやり直す |
| Esc | ゲームを終了する |

### ゲームオーバー画面

| キー | 操作 |
|---|---|
| ↑ ↓ | 項目を選ぶ |
| Enter / Space | 決定する |

## ビルド方法

### 必要なもの

- CMake 3.16 以上
- C++17 に対応したコンパイラ
- Git（SDL3 のソースをビルド時に自動で取得するため）

SDL3 は CMake の FetchContent で自動的にダウンロードしてビルドするので、別途インストールする必要はありません。

### 手順

```sh
cmake -S . -B build
cmake --build build
```

ビルドが終わると、`assets` フォルダが実行ファイルの横に自動でコピーされます。実行ファイルは `build` フォルダ（Visual Studio のジェネレーターでは `build/Debug` など）にできます。

### 動作確認した環境

- Windows 11
- Visual Studio 2026（MSVC）+ Ninja

Windows では「Developer Command Prompt for VS」など、MSVC が使えるターミナルから実行してください。

## フォルダ構成

```
tetris_cpp/
├─ CMakeLists.txt
├─ assets/                 … BGM・効果音（WAV）
└─ src/
    ├─ main.cpp              … 初期化とメインループ
    ├─ config.h              … 盤面サイズ・落下速度・得点などの定数
    ├─ pieces.h              … ミノの形
    ├─ game_event.h          … ゲーム内の出来事（効果音のきっかけ）
    ├─ tetris.h / .cpp       … ゲームのルール
    ├─ game_over_screen.h / .cpp … ゲームオーバー演出とメニュー
    ├─ renderer.h / .cpp     … 描画
    └─ audio.h / .cpp        … BGM・効果音の再生
```

### サウンドファイル

`assets` フォルダに次の WAV を置くと再生されます。ファイルが無い音は鳴りませんが、ゲームはそのまま遊べます。

| ファイル | 用途 |
|---|---|
| `bgm.wav` | BGM |
| `se_move.wav` | 左右移動 |
| `se_rotate.wav` | 回転 |
| `se_lock.wav` | 着地 |
| `se_clear.wav` | ライン消去（1〜3ライン） |
| `se_tetris.wav` | 4ライン消し |
| `se_gameover.wav` | ゲームオーバー |
